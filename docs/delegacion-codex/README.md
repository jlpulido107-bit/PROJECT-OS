# Archivos para SIGSAH y RADAROS

Copias listas para agregar a cada repositorio mediante su propio PR (desde PROJECT-OS no se modifican repositorios
fuente). Cada carpeta refleja la ruta final dentro del repositorio:

- `sigsah/AGENTS.md` y `sigsah/.github/ISSUE_TEMPLATE/tarea-codex.yml` → repositorio SIGSAH.
- `radaros/AGENTS.md` y `radaros/.github/ISSUE_TEMPLATE/tarea-codex.yml` → repositorio RADAROS.
- `*/.claude/skills/` (`planear-proyecto` y `orden-codex`) → la misma copia en cada repositorio; el original está en
  `.claude/skills/` de PROJECT-OS.

Protocolo: [`../delegacion-codex.md`](../delegacion-codex.md).
