# Plantilla del repositorio NOTAS

Copia el contenido de esta carpeta a la raíz del repositorio privado `jlpulido107-bit/NOTAS` y crea además las
carpetas `00-entrada/` y `privado/` (vacías). Todo aquí es de ejemplo: no hay ideas reales.

Reglas, formato del índice y flujo: `docs/notas.md` de PROJECT-OS.

- [POS](POS/indice.md) · [SIG](SIG/indice.md) · [ECO](ECO/indice.md) · [DEV](DEV/indice.md)
- Nota de ejemplo: [POS/ejemplo-idea.md](POS/ejemplo-idea.md).

En NOTAS no van datos clínicos, de pacientes, personales ni secretos.
